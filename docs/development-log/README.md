# Development Log

Development logs are organized chronologically.

## Naming convention

```
YYYY-MM-DD-short-topic.md
```

Examples:

- 2026-07-19-phase2-ui.md
- 2026-07-27-phase4-gameplay-ui.md
- 2026-08-03-session-bridge.md

Each log summarizes:

- work completed
- architectural decisions
- validation performed
- remaining work
