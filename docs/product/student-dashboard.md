# Student Dashboard Product Overview

## Product Goal

Give students one clear place to begin practice, open educational tools, and understand what to work on next.

## Primary Users

- elementary students, often using tablets
- middle school students, often using tablets or laptops
- high school students, primarily using laptops

## Current MVP

The MVP provides:

- student-specific login destination
- Marketplace entry point
- Note Detective access
- protected student-only routing

## Product Principles

- simple before comprehensive
- practice-focused
- easy to scan
- usable without adult assistance
- responsive across tablets and laptops
- expandable without becoming cluttered

## Future Capabilities

- assignment overview
- practice reminders
- teacher recommendations
- progress snapshots
- learning streaks
- multiple educational applications
- personalized activity suggestions

## Design Status

The current UI is a functional placeholder.

A dedicated Student Dashboard design task has been assigned separately so the long-term visual direction can be developed without constraining it to the initial implementation.
