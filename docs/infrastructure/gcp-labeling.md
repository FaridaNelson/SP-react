# GCP Labeling Standard

## Required Labels

project
environment
owner
managed-by

## Optional Labels

service
purpose
cost-center

## Examples

### OpenClaw

project=openclaw
environment=development
owner=farida
managed-by=manual
purpose=ai-agent-lab

### StudioPulse API

project=studiopulse
environment=production
owner=farida
managed-by=manual
service=api
